# Common Data

## Purpose

This directory holds shared content used across multiple pages.

It should contain content that does not belong to a single page:

- site identity,
- navigation labels,
- shared call-to-action copy,
- shared footer content,
- reusable trust language,
- shared legal or contact references.

## Rules

- Keep shared data minimal and stable.
- Do not place page-specific content here.
- Do not duplicate content that belongs in a page directory.
- If a value changes often because it is page-specific, keep it in the page directory instead.
