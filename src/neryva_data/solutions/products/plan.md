# Solutions Product Catalog Plan

## Objective

Define the solution catalog before implementation so the site can support product detail pages under `/solutions/$slug`.

## Final Content Model

Recommended files:

- `catalog.json`
- one JSON file per product

## Catalog Responsibilities

The catalog should list:

- product slug,
- title,
- short summary,
- status,
- primary value,
- route hint if needed.

## Product File Responsibilities

Each product file should include:

- hero copy,
- problem statement,
- solution summary,
- what it is for,
- what it is not for,
- optional proof or evidence notes,
- CTA.

## Content Standards

- Keep the language concrete.
- Do not overpromise product maturity.
- Do not turn product pages into generic sales copy.
