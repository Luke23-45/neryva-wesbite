# Blog Page Data Plan

## Objective

Define the Blog page content before implementation so the page can be rebuilt without relying on the legacy article dataset.

## Final Content Model

Recommended files:

- `page.json`
- `sections/hero.json`
- `sections/posts.json`

## Section Responsibilities

### Hero

Purpose:

- set the tone for technical writing,
- make the page feel deliberate rather than generic.

### Posts

Purpose:

- list articles when they exist,
- show a clean early-stage empty state when they do not.

## Content Standards

- Keep the page concise and technical.
- Do not fabricate content.
- Empty is acceptable if the writing program is still early.
