# Events Page Data Plan

## Objective

Define the Events page content before implementation so the page can be rebuilt without relying on the legacy event dataset.

## Final Content Model

Recommended files:

- `page.json`
- `sections/hero.json`
- `sections/events_list.json`

## Section Responsibilities

### Hero

Purpose:

- set the page tone,
- explain what kinds of events belong here.

### Events List

Purpose:

- list real events when they exist,
- provide a clear empty state when there are none.
